## 3. T4: KB 校验整理 (FAIR — 时序问题非系统bug)

T4 在并行测试期间运行，其他 6 个 Agent 同时在 E2E-Integration-Test 中创建/删除文档。T4 看到了 8 个文档（含 3 个其他 Agent 正在操作的 Fulltest-* 文档），但当 T4 尝试读取时这些文档已被删除。

**验证**: 测试结束后复查 kb_get_documents 返回稳定的 5 个文档，无幽灵。已清理 13 个孤儿标签。

**真实健康分** (清理后): ~95/115 (82.6%) — 元数据一致性恢复，孤儿标签清零。

## 4. T5: 经验管道 (8/8 PASS)

### 内容验证门控效果（关键差异化能力）

| 查询 | 向量召回 | 关键词召回 | 返回结果 | 评价 |
|------|:--------:|:---------:|:--------:|------|
| 深度学习优化 | 3 | 0 | **0** (3/3 discard) | ✅ **诚实空回——拒绝伪造** |
| 电池热管理 | 0 | 1 | 1 P2 (不相关) | ⚠️ 降级模式引入噪声 |
| VLA训练 | 0 | 5 | 2 P1 + 3 P2 | ✅ 命中2条高相关经验 |

**关键发现**: 
- 内容验证门控有效拦截了 3 个向量分虚高但内容不相关的候选——这正是 content-overrides-vector 原则的实证
- 降级搜索（3轮阈值放宽）有引入 false positive 的风险（Q2返回不相关P2）
- AI-ML-Research 经验库质量: 7条经验, 3条P1(credibility 0.74-0.80), 4条P2(0.30)
