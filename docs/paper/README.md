## 🚀 工作流

```
1. 读 FINAL-POTENTIAL-ASSESSMENT.md     → 理解真实能力与边界
2. 读 APPLIED-PAPER-FRAMEWORK.md         → 掌握写作框架
3. 执行 AGENT-TEST-PROMPTS.md            → Agent 跑实验（EXP-A/B/D）
4. 填 REPORT-TEMPLATE.md                 → 产出报告
5. 按 APPLIED-PAPER-FRAMEWORK.md 写论文  → 投 CIKM Applied
```

- Day 5: 消融 + 错误分析
- Day 6: 统计检验 + 画图
- Day 7+: 写论文（按 Applied 框架）
