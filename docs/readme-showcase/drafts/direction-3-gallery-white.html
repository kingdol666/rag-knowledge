§ 1 — The protocol

A gate that reads.

Vector recall makes the shortlist. Then the system reads each candidate and scores it 0–8 — topic, scenario, evidence. Six and above answer; five goes to the librarian; below that is discarded. If nothing passes, the answer is “not found” — on purpose.

0–4 · discard
5 · librarian
6–8 · fast exit
off-topic · tangentialtargeted re-search + continuation readsanswer now, cite part & section

§ 3 — Organization

The other half of the contract.

Ingestion parses with MinerU, routes each paper into a category base by reading its content, keeps section headers on every part, and propagates tags to all 165 parts. Verified 50/50.
