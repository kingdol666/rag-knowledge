§1The gate is the protocol

Vector recall produces a shortlist. The QDCVR content gate reads each candidate and scores it 0–8 — topic, scenario, evidence — before anything reaches the answer. Fails escalate to a librarian; nothing passes, the system says not found.

§3Organization is the other half

Ingestion parses with MinerU, routes each paper into a category base by reading its content, keeps section headers on every part, and propagates tags to all of them. 50/50 parse-verified · 50/50 content-routed · 165/165 parts tagged.

Fig. Platform architecture — ingestion, content-routed category bases, QDCVR retrieval protocol, and the agent/MCP surface.

§4Honest by contract

Three out-of-corpus probes returned explicit not-found reports — zero fabrication. The scripted regression scores 9/10; the one miss is a chunk-window miss (doc_hit=true), identical across runs, and is declared rather than papered over.
