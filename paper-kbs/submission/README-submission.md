# KBS submission package

Generated by `make_submission_package.py`. Everything sits at ONE folder level, as
Editorial Manager cannot process LaTeX submissions that contain subfolders.

- manuscript sources: main2.tex, n1_intro.tex, n2_related.tex, n3_overview.tex, n4_acquisition.tex, n5_organization.tex, n6_retrieval.tex, n7_implementation.tex, n8a_eval.tex, n8b_eval.tex, n8c_eval.tex, n9_discussion.tex, n10_threats.tex, n11_conclusion.tex, n_back.tex, n_appendix_tables.tex, tab_appendix_ranks.tex, highlights.tex
- bibliography: `refs.bib` + `refs_new_verified.bib`, and the generated `main2.bbl`
  (upload the `.bbl`, not only the `.bib`: .tex, .bbl, .bst, .sty, .cls are all
  'Manuscript' item types)
- figures: 9 vector PDFs, one file per figure, same base names as the
  `\includegraphics` calls: fig1_architecture.pdf, fig2_lanes.pdf, fig3_retrieval.pdf, fig4_inflation.pdf, fig5_e2e.pdf, fig6_margin_variants.pdf, fig7_ood.pdf, fig8_anatomy.pdf, fig9_robustness.pdf
- `highlights.docx`: 3-5 bullets, each at most 85 characters, no jargon
- `highlights.tex`: the same bullets for the `highlights` environment

## Author actions before upload (not automatable)

1. Replace the author placeholders in `main2.tex` (`Author Name`, `Co-author Name`,
   affiliation, `author@example.com`) and the three `AUTHOR ACTION` markers.
2. Complete Elsevier's declaration of competing interests at
   declarations.elsevier.com, export it as .doc/.docx, and upload it separately.
3. Confirm the funding sentence in `n_back.tex` and add ORCIDs where the submission
   system asks for them (the KBS guide itself does not mandate ORCID in the PDF).
4. Optional: graphical abstract is NOT required by KBS; if supplied it must be
   1328x531 px minimum, 300 dpi, RGB, fonts Arial/Times/Courier/Symbol.
