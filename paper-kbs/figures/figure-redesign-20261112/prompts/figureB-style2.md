# HMRS Figure B — Style 2 visual direction board

Warm ivory editorial research-diagram direction board for a knowledge-document system. Use two calm, balanced horizontal lanes with a centered persistent-state bridge. Upper lane is knowledge creation and maintenance, flowing from heterogeneous source documents through parsing and QC, structural enrichment, content-based placement, state persistence, and conditional indexing. Lower lane is question-to-evidence: scope, workflow choice, candidate gathering, optional evidence judge, then a green supported-answer branch, a neutral scoped-not-found branch, and an amber execution-failure branch. Deep navy typography, muted teal process line, amber decision marker, soft violet state bridge, restrained coral for failure. Flat vector geometry, generous whitespace, no illustrations, no 3D, no decorative database cylinders. This is a composition and palette reference only; all exact text and system semantics will be authored later as editable vector text. No generated labels, no invented guarantees, no watermark.
