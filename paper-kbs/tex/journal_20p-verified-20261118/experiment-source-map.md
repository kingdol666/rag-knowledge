# Experiment source map (reproducibility record)

The article identifies runs by their design, not by calendar date. These names identify records, not independent samples. Paths below are relative to the project repository unless marked as package files. Where raw material cannot be redistributed, the listed package artifacts support checking the reported metrics from saved labels or sanitised assertions. They are not an end-to-end replay.
