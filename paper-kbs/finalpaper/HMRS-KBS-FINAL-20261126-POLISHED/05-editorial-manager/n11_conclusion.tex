\section{Conclusion}
\label{sec:conclusion}

HMRS gives agents a workflow for managing changing documents and inspecting
scoped candidate passages and their source references. It makes the corpus
hierarchy available at query time: content-informed placement and descriptions
help agents choose a collection and document, while source references locate
returned text for inspection. The hierarchy makes scope explicit; it neither
replaces lexical or vector retrieval nor guarantees that every call stays within
the intended scope.

The evaluation shows what this design provides and what it leaves unresolved.
A rename-and-move probe found stale index entries, so correct filing did not
guarantee current index visibility. In the routing tests,
the configuration with descriptive cards reached the labelled collection
more often than the nominally name-only configuration, although those
runs do not isolate the effect of descriptions. Correct routing still
left some evidence packs without the literal target string. Combining
scored document text with an extra vector search and prioritised windows
increased target-string containment, a text-coverage proxy, relative to the
reference configuration across three runs on the same questions. The
configuration changes were not isolated, and the result does not establish
that the hierarchy itself caused the increase. In the fixed-pool replay,
ordering by verifier score instead of fused rank reduced top-five
gold-document hits. Neither literal containment nor a top-five hit establishes
support for an answer.

The blind deployment comparison found no statistically significant paired
difference after correction. Because the deployments differed in search scope
and source access, it was not a matched test of answer quality. HMRS therefore
provides an integrated management--retrieval workflow with separate checks for
document visibility, searched scope and retrieved text. It does not yet establish
improved claim-level grounding or end-to-end answer quality over a tool-matched
flat alternative. A follow-up study should measure claim-level support on
independent questions under matched search scopes, reading budgets and
source-access conditions.
