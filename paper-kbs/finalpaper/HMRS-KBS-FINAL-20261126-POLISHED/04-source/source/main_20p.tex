\begin{abstract}
In changing document collections, a passage can resemble a query without
coming from a source that applies to the task. The Hierarchical Management
Retrieval System (HMRS) uses the same collection hierarchy to file and
retrieve documents. At ingestion, an agent uses recovered text for placement
and description. In catalogue-first mode, the query agent chooses a
collection, consults its document listing and reads selected sources. Lexical
and vector search can retrieve candidates in a specified scope, and an
optional scorer can filter passages without reordering documents. A
rename-and-move probe exposed stale index entries. In scripted routing tests,
the configuration with descriptive cards reached the labelled collection more
often, but the comparison did not isolate the effect of descriptions. Even
correct routing did not ensure that the returned evidence contained the
literal target string. A configuration combining scored document text, extra
vector search and prioritised windows contained more target strings than the
reference configuration in three runs on the same questions. On fixed candidate
pools, verifier-score ordering yielded fewer top-five gold-document hits than
fused ranking. The blind deployment comparison did not use catalogue-first
routing and found no statistically significant paired difference after
correction for multiple comparisons. HMRS makes it possible to check where an
agent searched and which source passages it returned; neither check establishes
that the passages support the answer.
\end{abstract}
