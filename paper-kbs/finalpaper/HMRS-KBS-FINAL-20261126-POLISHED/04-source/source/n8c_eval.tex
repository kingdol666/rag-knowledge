\subsection{Using verifier scores to admit or rank evidence (E6)}
\label{sec:e6}
\label{sec:inflation}\label{sec:eval-verify}\label{sec:exp-e6}
A score that is suitable for admitting passages need not work as a ranking
score. The hybrid tool of Section~\ref{sec:gate} uses the verifier score in
both roles, so we tested the second one directly. We took 16 candidate pools
from the historical hybrid wrapper and changed only their order. Under
verifier-score order, the number of pools with a gold document in the top
five fell from 15 to seven: eight pools lost a hit and none gained one
(exact McNemar $p=0.0078$).

All 191 recorded scores in the separate archive exceeded the 0.5 cutoff,
so this record provides little evidence about the value of filtering. In a
reconstructed replay with fixed candidates, the filtered and unfiltered arms
retained the same number of documents on nine of ten questions; the archive
does not establish that they retained the same documents. The reordering
result does not show whether filtering helps.

\subsection{What answer traces and success status reveal (E7)}
\label{sec:e5}
\label{sec:agentic}\label{sec:abstention}\label{sec:composition}\label{sec:eval-agent}
\label{sec:sysarms}\label{sec:e7}\label{sec:exp-e7}
On a shared five-collection corpus, each of three interfaces (platform, file
and chunk-replica variants) included citation markers in nine of ten answers. A marker records an attempt to
cite; it does not show that the source supports the claim. Abstention was
not uniform. In three industrial-domain probes with no in-corpus answer, the
instructed agent reported not found in all three completed runs; this is an
observation of instructed agent behaviour, not a server-side guarantee. In a
separate probe family, the retrieval layer still returned candidates above
the 0.35 threshold for absent topics, so the threshold is not a test of
answerability.

The deployment probes exposed a different ambiguity: global search could
report success after skipping unreadable collections. In the reindex
diagnostic, scoped search already found the affected document, whereas
global search omitted it until the affected collection was forcibly
reindexed; global search then returned the document. Pagination recovered a
shelf listing cut off by the output limit. Reporting the scope searched and
any skipped collections makes it possible to distinguish incomplete search
from a completed search that found no evidence.

The earlier retrieval measures answer narrower questions. Target-string
containment measures text coverage (Figure~\ref{fig:content}). In the
fixed-pool replay, a top-five hit measures document position; the paired
outcomes appear alongside the score distributions (Figure~\ref{fig:verifier}).
Neither measure establishes that a cited passage supports the answer.
