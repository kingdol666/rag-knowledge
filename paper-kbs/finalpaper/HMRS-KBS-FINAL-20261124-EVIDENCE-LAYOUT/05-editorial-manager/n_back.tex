\section*{Data availability}
The implementation and benchmark scripts are available at
\url{https://github.com/kingdol666/rag-knowledge}. The submission's
benchmark snapshot, \path{benchmark-suite/paper-results-kbs-20261125},
provides the records underlying the reported results, together with a
crosswalk and recomputation checks. It includes the separately captured
workflow in Figure~\ref{fig:tiered-case}; that record is not pooled with the
answer-quality comparison or the routing audit. The routing and containment
traces omit returned passages and reference strings. The repository provides
a recipe and synthetic sample for constructing a substitute for the
42-document industrial demonstration corpus.
