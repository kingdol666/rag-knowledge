## System facts (verifiable in repo)
- 41 kb_* knowledge-management tools inside a 94-tool MCP inventory.
- Rubric: s = s_topic (0–3) + s_scenario (0–3) + s_evidence (0–2), max 8; ≥6 cited answer; =5 attributed backstop; ≤4 discarded; failed gate → librarian browsing (base summaries, tag-matched shelves, targeted re-search).

- Storage: ChromaDB + BGE-M3 vectors, Neo4j relations, Markdown + JSON/YAML metadata. Graph navigation optional, NOT the evaluated route.
- Interfaces: web console, FastAPI, ragctl CLI, MCP server — same tools.
