\section{Interactive Demonstration}
\label{sec:demo}

The demonstration targets research-data administrators and agent developers.
A prepared instance contains 50 papers in five bases. Attendees inspect
documents in the web console and operate an MCP-capable agent with the
packaged skills loaded. The presenter provides the candidate excerpts and
answer records alongside the console; ordinary web search is not presented
as an equivalent execution of the skill.

\paragraph{1. Organize a document.}
An attendee selects a PDF and an intake location, then asks the agent to
parse and organize it by content. The attendee compares the parsed text with
the proposed category, inspects the parts, and checks tags and indexing
status. This exposes the routing decision and the operations needed to make
the document searchable. A prepared example, explicitly identified as such,
is available if live parsing would delay the session.

\paragraph{2. Inspect an answer's evidence.}
The attendee asks, ``What defines NISQ technology and what is its central
limitation?'' In the supplied BQ02 trace, the first hit is part 2 of 3 of the
NISQ paper, with similarity approximately 0.71. The recorded agent judgment
is 8/8 and takes the direct-answer path. Attendees open the source and
compare it with the answer: similarity, agent judgment, and evidence are
distinct. Figure~\ref{fig:threeway} adds a Transformer case comparing
trace-derived section references, a self-reported filename, and a
baseline abstention.

\paragraph{3. Inspect a not-found report.}
The attendee asks for training epochs in the fictitious paper
\emph{Spectral Tuning for Low-Resource Odor Recognition}. The scripted P2
example pairs collected retrieval and catalog evidence with a predefined,
agent-authored judgment: BERT discusses training epochs but receives 1/8,
and the saved report states not-found rather than substituting BERT's recipe.
Its catalog census covers five bases and 165 entries, not exhaustive
reading of all documents. Attendees inspect the near miss and search scope
and may try another question. The report concerns evidence in this
collection, not the existence of an answer elsewhere.
