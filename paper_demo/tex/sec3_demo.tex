\section{Interactive Demonstration}
\label{sec:demo}

The demo is designed for research administrators and agent developers.
Attendees use the web console to browse and organize a collection, then
inspect an agent trace through the MCP tools; the \texttt{ragctl} CLI
provides an alternative operator interface. The paper reports two
separate snapshots: a 100-paper collection for the ingest audit in
Table~\ref{tab:pipeline}, and the ten-domain evaluation corpus in
Section~\ref{sec:eval}. The three-minute video is an earlier interface
walkthrough of a 50-paper deployment with a legacy 0--8 gate; it does not
show the current 100-paper snapshot or Laya threshold used in Section~\ref{sec:eval}.
None of the paper's measurements come from the video.

\paragraph{1. Organize a document.}
The attendee selects a source file and follows its parse result,
content-based base assignment, tags, five-dimension description, split
parts, and index check. The same address appears in the collection
browser and relation graph. A failed content or index check is visible
before the ingest is reported complete.

\paragraph{2. Inspect answer evidence.}
The attendee asks which three ontologies subdivide the Gene Ontology.
In the saved BQ04 trace, the fast lane recalls a primer, the judge retains
answer-bearing segments, and the agent reads the cited part. The answer
names Molecular Function, Biological Process, and Cellular Component;
its source block gives the base, document, part, and section
(\texttt{2. What is the Gene Ontology?}). The attendee can open that
source in the console.

\paragraph{3. Examine a failure report.}
The attendee asks for training epochs from the fictitious paper
\emph{Spectral Tuning for Low-Resource Odor Recognition}. The trace
contains ten generic two-stage hits, a top vector similarity of 0.52,
twelve weak title-token matches, and no relevant segment for the
judgment engine to grade. BERT fine-tuning recipes appear as near-misses
and are not used to answer. The system returns a scoped not-found report
and suggests searching by an exact identifier; it does not infer epoch
values from unrelated documents.

Mechanized queries complete in about twenty seconds in the demonstration
setup; sampled native-agent sessions take 220--350 seconds. The video
and saved traces let attendees inspect these interactions alongside a
live query.
