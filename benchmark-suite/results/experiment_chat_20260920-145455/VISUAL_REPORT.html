Here is the answer. --- ## How the Transformer Computes Attention, and Why It Replaces Recurrence and Convolution **Source:** *Attention Is All You Need* (Vaswani et al., 2016), arXiv:1706.03762 — KB `计算机与人工智能` (Computer Science and AI), doc `artificial-intelligence__1706.03762__attention-is-all-you-need.md` (parts 1 & 2). ### 1. What an attention function is An attention function maps a **query** and a set of **key–value pairs** to an output, where query, keys, values, and output are all vectors. The output is computed as a **weighted sum of the values**, where the weight assigned to each value is computed by a **compatibility function of the query with the corresponding key** (Section 3.2). ### 2. Scaled Dot-Product Attention (Section 3.2.1) Inputs: queries and keys of dimension `d_k`, values of dimension `d_v`. The recipe: 1. Compute the **dot products** of the query with all keys, 2. **Divide each by √d_k** (the scaling factor), 3. Apply a **softmax** to obtain the weights on the values. Batched into matrices Q, K, V, the output is: $$\mathrm{Attention}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V \quad \text{(Eq. 1)}$$ **Why the √d_k scaling:** the paper contrasts additive attention (a feed-forward net with one hidden layer) with dot-product attention. For small `d_k` the two perform similarly, but unscaled dot-product attention **underperforms additive attention for large `d_k`** — because for large `d_k` the dot products grow large in magnitude, **pushing the softmax into regions where it has extremely small gradients**. Scaling by 1/√d_k counteracts this. Dot-product attention was chosen anyway because, despite similar theoretical complexity, it is **much faster and more space-efficient in practice** since it can use highly optimized matrix-multiplication code. ### 3. Multi-Head Attention (Section 3.2.2) Rather than one attention function over `d_model`-dimensional keys/queries/values, the model **linearly projects Q, K, V `h` times** with different learned projections to `d_k, d_k, d_v`; attention runs **in parallel** on each projected version, the `d_v`-dimensional outputs are **concatenated and projected** once more: $$\mathrm{MultiHead}(Q,K,V) = \mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^O,\quad \mathrm{head}_i = \mathrm{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$ Rationale: **multi-head attention lets the model jointly attend to information from different representation subspaces at different positions**; with a single head, averaging inhibits this. In the paper: `h = 8`, `d_k = d_v = d_model/h = 64`; because each head is lower-dimensional, total cost ≈ single-head attention at full dimensionality. Ablations confirmed this matters — single-head attention was 0.9 BLEU worse than the best setting. **Three applications in the model (3.2.3):** (a) *encoder–decoder attention* — queries from the previous decoder layer, keys/values from the encoder output; (b) *encoder self-attention* — Q, K, V all from the same place (the previous encoder layer), every position attends to all positions; (c) *decoder self-attention* — masked (illegal connections set to −∞ before softmax) so position *i* can only attend to positions ≤ *i*, preserving auto-regression. ### 4. Why it replaces recurrence and convolution (Sections 1, 2, 4 — §4 "Why Self-Attention") The paper judges layer types on **three desiderata**: (i) **total computational complexity per layer**, (ii) **amount of parallelizable computation** (minimum number of sequential operations), (iii) **path length between long-range dependencies** — shorter paths make long-range dependencies easier to learn. **Against recurrence.** Recurrent models factor computation along symbol positions, generating hidden state `h_t` as a function of `h_{t-1}` and the input at *t*. This **inherently sequential nature precludes parallelization within training examples**, which becomes critical at longer sequence lengths. As Table 1 shows: | Layer Type | Complexity/Layer | Sequential Ops | Max Path Length | |---|---|---|---| | **Self-Attention** | O(n²·d) | **O(1)** | **O(1)** | | Recurrent | O(n·d²) | O(n) | O(n) | | Convolutional | O(k·n·d²) | O(1) | O(log_k n) | | Self-Attention (restricted) | O(r·n·d) | O(1) | O(n/r) | A self-attention layer **connects all positions with a constant number of sequentially executed operations**, whereas a recurrent layer needs **O(n)** sequential operations. Self-attention is also faster than recurrent layers **when sequence length n < representation dimensionality d** — typically true for word-piece/byte-pair sentence representations in MT. **Against convolution.** A single convolutional layer with kernel width `k < n` **does not connect all pairs of input/output positions**; doing so requires a stack of `O(n/k)` layers (contiguous kernels) or `O(log_k(n))` (dilated), **increasing the longest path length**. Convolutional layers are generally **more expensive than recurrent layers by a factor of k**; separable convolutions reduce this to `O(k·n·d + n·d²)`, but **even with k = n, a separable convolution's complexity equals the combination of a self-attention layer plus a point-wise feed-forward layer** — exactly the Transformer's design. In the Transformer, the number of operations relating any two positions is **reduced to a constant**, versus linearly (ConvS2S) or logarithmically (ByteNet) growing with distance in the convolutional baselines. **Novelty claim (Section 2):** the Transformer is **the first transduction model relying entirely on self-attention to compute representations of input and output without using sequence-aligned RNNs or convolution.** *(Note the trade-off the paper itself flags: constant path length comes "at the cost of reduced effective resolution due to averaging attention-weighted positions," counteracted by Multi-Head Attention.)* Because there is no recurrence and no convolution, **positional encodings** (sinusoidal functions of different frequencies — Eq. in 3.5) are added to the input embeddings so the model can use token order. **Payoff (Abstract, §5.2, §6):** the architecture is "superior in quality while being more parallelizable and requiring significantly less time to train" — 28.4 BLEU on WMT 2014 EN–DE (beating prior best, including ensembles, by >2 BLEU), 41.8 BLEU EN–FR after 3.5 days on 8 GPUs; the base model trained in 12 hours, at a small fraction of prior training cost (Table 2: base 3.3×10¹⁸ FLOPs vs. e.g. ConvS2S 9.6×10¹⁸). A **side benefit** noted in §4: self-attention can yield **more interpretable models** — individual heads learn different tasks and exhibit behavior related to syntactic/semantic structure (Figures 3–5 show long-distance dependency and anaphora-resolution heads). ### Sources - `计算机与人工智能/artificial-intelligence__1706.03762__attention-is-all-you-need.md (part 1 of 2).md` — KB `计算机与人工智能` (kb_id `b1199132-e4d4-4305-8c2e-82dc1753b0ba`); Abstract, §1 Introduction, §2 Background, §3.2 Attention (3.2.1–3.2.3), §3.5 Positional Encoding, **§4 Why Self-Attention**, Table 1, §5.2. - `计算机与人工智能/artificial-intelligence__1706.03762__attention-is-all-you-need.md (part 2 of 2).md` — §6.2 Model Variations (head-count/k-dimension ablations), §6.3, §7 Conclusion. - Corroborating copies in the "DeepRead baseline reproduction" indexes: `Corpus-Struct/...__s01.md`, `Corpus-Chunks800/...__k02.md`, `Corpus-Paras/...__p04003.md` (same paper, same claim that the Transformer is the first model relying entirely on self-attention without sequence-aligned RNNs or convolution). **Certainty:** High — every claim above is quoted or directly paraphrased from the retrieved full text of the primary source, read end-to-end (no gap in the Section 4 argument).

The core mechanism: anionic charge compensation In conventional cathodes (LiTMO₂, TM = Ni/Mn/Co), charge is balanced by transition-metal oxidation: ``` LiTM³⁺O₂ —charging→ Li₍₁₋ₓ₎TM³⁺₍₁₋ₓ₎TM⁴⁺ₓO₂ + xLi⁺ + xe⁻ (1) ``` But many cathodes deliver **overcapacity exceeding the transition-metal oxidation limit**. The reversible process is summarized as: ``` O²⁻ ⇌ (O₂)ⁿ⁻ (2) ``` or, alternatively, as the formation of electron holes on oxygen (avoiding O₂ gas evolution). ### 2. Why it works: "orphaned" O 2p states The enabling structural feature is **Li-excess (or Na-excess) environments**. In normal LiTMO₂, every O is coordinated by 3 TM + 3 Li. TM–O hybridization pulls the bonding O 2p states down to the bottom of the valence band (~10 eV below E_F). In **Li-excess Li₂TMO₃**, the TM layer also contains Li, so some O ions are coordinated by **fewer than three TM ions** (Li–O–Li coordination). Both O and TM can then donate/accept electrons during redox.
