## 4. 诚实披露

1. 判分为确定性词边界正则、不含语义等价识别 → 口径偏保守（BQ02/A 即此类）。
2. A 轨 input tokens 显著高于 B/C（QDCVR 把验证后正文装入上下文），成本以 total_cost_usd 为准（已含缓存读）。
3. LLM 通道有方差：本轮与历史 run（110759 / 181449）同量级但不逐题相同；本报告只描述本轮 run，未做跨轮挑选（PIPELINE 红线 5）。
4. C 轨检索对象是固定分块复刻库（Chunks800），与五门类库分块不同——这正是实验要对照的"检索协议"差异（A=平台库+QDCVR，B=原始文件，C=Chunks800）。
5. 本轮在 2026-09-23 平台优化（MCP 双前缀兼容等 12 项修复，见 review/stress-20260923/OPTIMIZATION-REPORT.md）之后执行：A 轨 0 工具被拒，历史"工具前缀漂移导致 MCP 调用全拒"的失效模式已消除并回验。

## 5. 结论与改进方向

1. **设计有效性成立**：同一语料、同一题集、同一 harness、同一对外端点，仅检索协议不同——三轨差异完全由检索策略解释（A 9/10 > B 6/10 > C 5/10）。平台化 RAG 的价值被量化为：**+30~40pp pass 率，代价 ≈3× 成本与 2.6× 时延**。
2. 裸 Agent gold 10/10 说明**文件定位不是瓶颈，答案合成质量才是**；改进方向：B 侧多文件交叉阅读，C 侧 chunk rerank/多轮检索。
3. A 侧降本方向：QDCVR 的 token 开销（BQ03 in=109k）可通过检索结果压缩优化。
4. 环境漂移（工具命名空间、语料规模门槛）是复刻实验的首要失效模式——本轮设计审查把它们在跑前全部拦截。
