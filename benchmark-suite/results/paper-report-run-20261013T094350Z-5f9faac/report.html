**Answer**

The Transformer computes attention as a mapping of a query and a set of key-value vector pairs to an output that is a weighted sum of the values, where each weight is a compatibility score between the query and the corresponding key. Specifically, scaled dot-product attention takes dot products of the query with all keys, divides each by √d_k, and applies softmax to obtain the weights on the values, packed in matrix form as Attention(Q,K,V) = softmax(QKᵀ/√d_k)V. Multi-head attention linearly projects Q/K/V h times (h=8, d_k=d_v=64), runs the attention function in parallel on each projection, then concatenates and projects the results, letting the model jointly attend to different representation subspaces. The replacement of recurrence and convolution is motivated by three desiderata: computational complexity per layer, parallelizable computation (minimum sequential operations), and maximum path length between long-range dependencies. A self-attention layer connects all positions with O(1) sequential operations and O(1) path length, whereas a recurrent layer requires O(n) sequential operations and O(n) path length — recurrence's inherently sequential h_t = f(h_{t-1}) dependency precludes parallelization within training examples — and a single convolutional layer with kernel k<n cannot connect all pairs, requiring O(n/k) stacked or O(log_k n) dilated layers and costing k× more than recurrent layers. Self-attention is faster than recurrent layers when sequence length n < representation dimension d, and even a separable convolution with k=n only matches a self-attention layer plus a point-wise feed-forward layer. The paper also notes self-attention may yield more interpretable models, and states the Transformer is the first transduction model relying entirely on self-attention without sequence-aligned RNNs or convolution. Because it contains no recurrence or convolution, sinusoidal positional encodings are added to the input embeddings to inject sequence order.
