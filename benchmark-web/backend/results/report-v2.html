4. Phase C: Content Verification — Key Observations

Observation 1: Vector can mislead — Adam optimizer case

Query R-06 "Adam优化器自适应学习率":
- Stage1 BM25 correctly ranked Adam.md at #1 (score 9.88)
- Stage2 Vector Rerank dropped Adam.md entirely — all 5 results were from RAG survey paper!
- Root cause: RAG paper contains "RL"+"reinforcement learning" terms matching vector space
- This is EXACTLY why Step 3 Content Verification is mandatory: vector score ≠ content relevance

Observation 2: Cross-KB fallback works

Query R-15 "RT-2 VLA model":
- Stage1 BM25 found only Embodied-AI KB docs → auto-upgrade triggered
- Cross-KB fallback supplemented with balanced vector search across all KBs
- Supplement found relevant docs from AI-ML-Research and Chemistry-Catalysis
- This is the QDCVR→Enterprise auto-upgrade mechanism working correctly
