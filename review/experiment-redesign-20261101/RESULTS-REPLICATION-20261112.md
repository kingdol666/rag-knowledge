## 3. 全部偏差的逐行归因（审计闭环）

1. **A0 的 4 例翻转**：F-hlm-2/3（0→1 **新增命中**）= 今晨 `s0j2` 文学-中文 chroma 干净周期重建的
   **修复效应**——终版该库带"段损坏"运行（RESULTS §4 的 17 受累行同源），重建后向量候选恢复正常，
   两题从第01回误选改为命中金标卷（第03/05回）。G-fyp-1（0→1）与 G-gwr-1（1→0）= 政务库内
   候选排序交换（同一库内 top1 在两份政府文件间互换）。净 +2。
2. **A0f/A0h/PD 共享的单例翻转**：`A-philosophy-en-walden` 1→0，三臂同 qid 同向 =
   检索索引态噪声（zarathustra part 20 挤入 top-6 候选），非臂间差异，非平台故障。
3. **floor dense/RRF 的偏差**（三态对账后定案）：
   - **F-bm25 三态完全一致**（24/40=60.0%，与终版逐题零翻转）——BM25 在本地语料文件上运行，平台无关。
   - **F-dense/F-rrf 对平台组成敏感**：dense 车道走 `kb_id=""` 全局搜索 + `balance_kbs` 跨库配平，
     其候选分布由"哪些集合存在且可读"决定。本轮实测三种平台状态：
     ① 陈旧孪生库可读（11:15 首跑）：dense 17/40，F-hlm-2/3 的 top1 被孪生库抢占；
     ② 孪生树删除后（12:58）：结果不变 → 追出 **5 个孤儿 chroma 集合**
     （今日孪生 2 个 + 旧代孪生/陈旧遗留 3 个，`kb_delete` 树删但 chroma 集合静默残留——重测轮已知陷阱复发）；
     ③ 孤儿全清后（13:2x，真卫生态）：dense 14/40，F-hlm-2/3 + 3 道 literature-en 题丢 gold——
     配平集合集变化 + 罪与罚 27 卷稀释全局候选槽位。
   - **结论**：floor 的 dense/RRF 列不是检索机制指标，是"平台组成指纹"。终版 19/26 与 R3
     14-17/24 的差异全部由上述已归因状态差异解释；机制性结论（BM25 精确复现）不受影响。
4. **A3 的 −8 行与路由重排**：见 §4。

## 4. A3 深查：为什么它是唯一数值敏感的臂

| 维度 | 终版 A3 | R3 A3 |
|---|---:|---:|
| gold | 45.8% (33/72) | 34.7% (25/72) |
| 路由正确 | 51.4% (37/72) | 68.1% (49/72) |
| 与 A0 端到端 | p=.4545（无显著差） | p=0.0026（显著劣化） |
| OOD 门控拒绝 | 0/4 | 4/4 |

**根因（backend 日志 + 逐题 trace 证据）**：A3 的路由卡是 name-only 薄卡（`# 库名`，
消融协议要求）——其语义信号本来就弱，路由落点高度依赖检索基础设施的瞬时状态。
终版跑 A3 时（11-03/11-10），路由卡库正处于 chroma 段损坏抖动期（旧 trace 里多题
`route_slug=""`，即卡检索空手而归、退回 bigram 描述路由器兜底——**兜底用的是完整库描述，
反而更有信息量**）；R3 跑 A3 时（11:49-12:00）卡库健康，薄卡检索全程在线，
路由被薄卡的弱信号主导 → 路由散布完全不同（41/72 题路由不一致），错库证据
（如 gov-zh 题的证据落到 wealth_of_nations）级联成 gold 翻转。

**这本身就是 H3 消融结论的直接证据**：去掉描述层后，路由质量从 A0 的 72/72 塌到
37-49/72（两次运行），且端到端数值随基础设施状态波动。**定性结论三次运行全部成立：
描述层是路由的支柱；没有它，路由不可靠。** 但 A3 的精确数值（33/72 或 25/72）
不应被单独引用——论文若引 A3，应引"路由质量塌陷 + 端到端不稳健"这一定性结论。

## 7. 复现方法论沉淀（比数字更重要的结论）

1. **机械臂是高确定性系统**：Laya 判卷 + 固定导航下，跨 run 逐题一致率 94-100%；
   A1b/A2（无导航/无判卷依赖路径）**零翻转**——这两个臂的数字可以直接当作确定性常数引用。
2. **翻转的三大来源全部可归因、可复现**：①平台基础设施状态（chroma 段健康度）
   ②语料库集合漂移（罪与罚 +27 卷、文学-中文重建）③索引态候选排序噪声（walden 例）。
   没有一例归因于"随机性"——每次翻转都能指出具体机制。
3. **97 数字对账口径不变**：终版数字保持权威；R3 作为独立复现证据并列呈现。
